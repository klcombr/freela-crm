## O que é

Um CRM leve feito pra quem trabalha sozinho. Gerencia leads, clientes, propostas e receita — tudo direto no navegador com localStorage.

## Features

- **Pipeline de Leads** — Kanban visual: Novo → Contato → Proposta → Fechado
- **Cadastro de Clientes** — Nome, empresa, email, telefone, notas
- **Tracker de Receita** — Registra pagamentos, calcula total mensal
- **Follow-ups** — Lembretes de retorno pra cada lead
- **Dashboard** — Visão geral: leads, conversão, receita
- **100% Local** — Dados ficam no navegador (localStorage)
- **Dark Theme** — Visual profissional, sem enrolação
- **Responsivo** — Funciona no celular e desktop

## Como usar

1. Abra `index.html` no navegador
2. Comece a adicionar leads
3. Arraste entre as colunas do pipeline
4. Acompanhe sua receita no dashboard

Sem instalação. Sem cadastro. Sem frescura.

## Stack

- HTML5
- CSS3 (variables, grid, flexbox)
- JavaScript vanilla
- localStorage
